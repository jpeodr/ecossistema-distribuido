O que é

Coletar a safra do Brasil inteiro, em paralelo

Em vez de consultar o IBGE estado por estado, produto por produto, o sistema divide o trabalho entre vários nós — e cada nó ainda divide de novo em threads.

Topologia distribuída

1 Manager coordena · 3 Workers processam · 4 MySQL persistem

Clique em Executar fluxo para percorrer as 6 etapas de uma coleta.

O fluxo em 5 passos

Da API do IBGE até o banco replicado

  1. Manager divide o Brasil em 27 tarefas (uma por estado) e joga na fila
  2. RabbitMQ entrega cada tarefa para um worker livre
  3. Workers consultam a API SIDRA — 4 produtos por vez, em threads
  4. Tudo é gravado no MySQL Master (única escrita)
  5. O Master replica para 3 slaves, que respondem as consultas
