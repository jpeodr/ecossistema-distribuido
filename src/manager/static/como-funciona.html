Como funciona

Fluxo de trabalho entre Manager, Redis, Workers e a API do SIDRA.

Resumo

  • O Manager fatia o job em uma tarefa por UF (27 tarefas).
  • As tarefas vão para a fila do Redis; qualquer Worker pode consumi-las.
  • Cada Worker consulta a UF no SIDRA e devolve os registros ao Manager.
  • Com todas as tarefas prontas, o Manager roda o REDUCE e libera o relatório.

Fluxo de trabalho #

1

Pedido

O navegador envia POST /api/v1/jobs com a pesquisa (LSPA ou PIM-PF).

Manager · src/manager/main.py
2

Fatiamento

O Manager obtém o período no SIDRA e divide o pedido em uma tarefa por UF (27 tarefas).

dispatcher · build_tasks()
3

Publicação

As tarefas são publicadas na fila do Redis (RPUSH em pipeline).

Manager · redis.pipeline()
4

Consumo

Cada Worker espera a fila com BLPOP e retira uma tarefa por vez.

Worker · worker/main.py
5

Coleta (MAP)

O Worker consulta a API do SIDRA, converte os números pt-BR e normaliza com pandas.

Worker · processor.py · sidra.py
6

Callback

O Worker devolve os registros ao Manager, que grava no SQLite e conta a tarefa como concluída.

Manager · /api/v1/internal/results
7

REDUCE

Quando todas as tarefas terminam, o Manager consolida os registros e gera o relatório.

Manager · analysis.py · reduce_results()
8

Leitura

A interface busca GET /api/v1/results e mostra as tabelas do relatório.

Três níveis de paralelismo #

Nível 1 · entre os nós

Distribuído

— tarefas

Uma tarefa por UF: cada tarefa é uma consulta independente ao SIDRA.

Nível 2 · dentro do nó

Assíncrono (I/O)

— tarefas em voo

Cada Worker mantém até WORKER_CONCURRENCY requisições simultâneas ao SIDRA (asyncio.create_task).

Nível 3 · dentro da tarefa

Thread (CPU)

1 thread dedicada

A normalização com pandas roda em asyncio.to_thread para não bloquear o event loop.

As fórmulas

Executadas no Manager, depois que todas as tarefas terminam.

soma = Σ valor(UF) média = Σ (valor(UF) × peso(UF)) / Σ peso(UF) part. % = 100 × valor(UF) / Σ valor(UF) HHI = Σ (part. % / 100)²
  • Soma — variáveis aditivas (produção, valor).
  • Média ponderada — variáveis de índice (preço, área média).
  • Participação — quanto cada UF responde pelo total.
  • HHI — concentração: <0,15 baixa · 0,15–0,25 moderada · >0,25 alta.

Falhas #

Rede

Retry com backoff

Falha no envio ao Manager ou no acesso ao SIDRA: o Worker repete a tentativa com espera de 1 s e 2 s, até MAX_RETRIES.

Tarefa

Reenfileiramento

A tarefa volta para a fila do Redis com a tentativa incrementada e vira falha definitiva depois de MAX_RETRIES.

Nó parado

Heartbeat

Worker sem heartbeat há 30 s (WORKER_STALE_SECONDS) sai da lista de ativos.

Escala

Mais nós

docker compose up -d --scale worker=5: a fila é compartilhada e os Workers novos consomem as mesmas tarefas.
